Add BoostHub to Your Home Screen

BoostHub includes a standard Web App Manifest (/manifest.json) so users can install it as an app-like shortcut on mobile and desktop browsers.

  1. Open the browser menu (three dots in the top-right corner).
  2. Tap Install app or Add to Home screen.
  1. Tap the Share icon at the bottom of Safari.
  2. Scroll down and tap Add to Home Screen.
  1. Look for the install icon in the address bar.
  2. Click Install to add BoostHub to your desktop.
Installed as a PWA, BoostHub works offline for cached pages and uses local browser storage for your demo wallet and orders.
